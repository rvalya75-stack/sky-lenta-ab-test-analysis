# Анализ A/B-теста эффективности push-уведомлений в ритейле

## Описание проекта

Анализ результатов A/B-теста для розничной компании SkyLenta с целью оценить влияние push-уведомлений на пользовательские метрики.

## Задачи проекта

- Провести исследовательский анализ данных (EDA)
- Проверить качество данных
- Выполнить сегментацию пользователей
- Сравнить показатели контрольной и тестовой групп
- Проверить статистические гипотезы
- Сформулировать выводы и рекомендации для бизнеса

## Используемые инструменты

- Python
- Pandas
- NumPy
- Matplotlib
- SciPy
- A/B testing
- Statistical hypothesis testing
- Excel
- Jupyter Notebook

## Этапы анализа

1. Загрузка и подготовка данных
2. Очистка данных и обработка пропусков
3. Расчёт ключевых метрик
4. Проверка статистической значимости различий
5. Формирование бизнес-выводов

## Результаты

В ходе анализа выполнено сравнение контрольной и тестовой групп, проведена статистическая проверка гипотез и сформированы выводы о влиянии push-уведомлений на ключевые пользовательские метрики.
